- The grid uses (row, column) coordinates; row index increases downward, column index increases rightward.
- The agent is represented as a set of cells (each with coordinates). The set can contain one or more distinct cells.
- Gray cells represent obstacles that can appear or disappear between states.
- At each timestep, exactly one agent cell moves by one cell in a cardinal direction. The action taken is that direction.
- Action "up" decreases the row index by 1.
- Action "down" increases the row index by 1.
- Action "left" decreases the column index by 1.
- Action "right" increases the column index by 1.
- The step count increments by 1 between consecutive states.
- The moving cell's target position must be within grid bounds. If the target cell currently contains a gray cell, that gray cell disappears in the next state (the agent cell occupies it). If the target cell already contains another agent cell, the two cells merge into one (the set loses one cell). If the target cell is empty (no gray, no other agent), the agent cell simply moves there.
- The other agent cells do not change position.
