# ada85_seed1 — regenerated (non-degenerate) ada85 data

`clean_data3/ada85` was generated at **seed=0**, which is PATHOLOGICAL for this game's
randomness. ada85 spawns Rocks on click, each carrying a HIDDEN boolean
`breaksBottle = (uniformChoice (list true false))`. Under seed 0 this collapses: **every**
rock spawned gets `breaksBottle=true` (verified 8/8), so the true/false randomness is never
exercised and every rock that reaches the bottle breaks it. (The original `../ada85/`
dynamics.txt understated this as "only the FIRST rock is true under seed 0" — it is all
rocks.) Under non-zero seeds you get a genuine true/false mix.

This dataset was regenerated by `prototypes/perc_invdyn/gen_ada85_seed1.py`: fresh
playthroughs through the real compiled interpreter under **non-zero per-episode seeds**
(train 101-108, test 301-302, test50 501-508, disjoint per split), **length 20** each.
Actions are applied via `env_utils.interpreter_action_to_text` + `interp.step()` with **no
manual coordinate swap** — the standard corpus replay path (same as `gen_s2kt7_seed1.py`).

Splits: train (8 eps), test (2), test50 (8) — full trajectories, so K-step temporal context
is available inline. Action whitelist: `noop,click`. Loaded counts (via
`build_optim_viz.load_transitions`, whitelist `{noop,click}`): train **152** transitions
(16 click = 8 `click 0 0` Suzie + 8 `click 0 10` Billy, 136 noop), test 38, test50 152;
context_k=0 and 3 both load.

## Replay consistency (the fix)

An earlier version applied clicks with a manual `interp.click(COL, ROW)` swap; that made the
recorded grids irreproducible under the standard replay path (`interpreter_action_to_text`,
which does NOT swap) and would be rejected by `test50_sim` / `verify_drive_in_sim`. This
version applies actions exactly like the standard path. **Validated: seed-aware replay via
`interpreter_action_to_text` from each episode's seed reproduces every recorded grid with 0
mismatched frames across all 18 episodes.**

Click labels are the ones that actually spawn under this path (`click A B` applies at
`col=A, row=B`): **Suzie = `click 0 0`**, **Billy = `click 0 10`** (NOT `click 10 0`, which
spawns nothing). The recorded observation header still says "click ROW COL"; that
ROW/COL-vs-COL/ROW header mismatch is a known corpus-wide issue handled uniformly elsewhere,
not per-game. The data here is simply self-consistent with the standard replay path.

## What the randomness looks like here (and the observability caveat)

- A Rock is ALWAYS a plain gray cell — `breaksBottle` is NOT rendered on the rock and is
  invisible while it travels. Its ONLY observable consequence is the **delayed bottle
  break**: a `true` rock reaching BottleSpot (5,10) turns the bottle broken (a GOLD cell
  appears at (5,10), col-10 palette flips) and it stays broken; a `false` rock reaches the
  same spot and produces NO change. A corner-spawned rock takes ~16-17 steps to arrive
  (break appears at spawn_frame + 17, +1 per intervening click freeze).
- **Caveat:** in a short (<~18-step) episode the rock never reaches the bottle, so true vs
  false rocks look identical and the VISIBLE dynamics are effectively seed-independent even
  though the hidden state varies. This data is deliberately length-20 with the determining
  rock spawned at frame 0 so the break lands inside the episode (frames 18-19). Result: the
  observed outcome tracks the seed's first draw — train episodes 1/3/5/7 (primary true)
  **show the break**; episodes 0/2/4/6 (primary false) **never break** — a real ~50/50 split
  that seed-0 data can never produce (seed 0 breaks in every episode).

## Seed provenance

Because the episodes are seed-varied they must be replayed from their own per-episode seed
(like `s2kt7_seed1` / `83wkq_seed1`). Seed-aware replay is 0-mismatch. A hardcoded seed-0
replay diverges only at the break frames of the no-break episodes — that divergence is the
intended non-degeneracy. See `dynamics.txt` for full mechanics.

Do NOT edit `../ada85/`; this is a separate, additive dataset.
