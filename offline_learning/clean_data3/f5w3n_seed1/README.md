# f5w3n_seed1 — regenerated (non-degenerate) f5w3n data

`clean_data3/f5w3n` was generated at **seed=0**, which is PATHOLOGICAL for this
space-invaders game's enemy-fire randomness. Enemies auto-fire one bullet every 15
ticks (rule `time % 15 == 3`) at a target chosen by `uniformChoice` over the combined
enemy pool (enemies1 row y=1 ∪ enemies2 row y=3, 10 enemies). Under seed 0
`uniformChoice` collapses to always returning the same index-0 enemy, so every fire
spawns at the enemies1 col-1 enemy — a fixed 2-value alternation `(2,1)/(1,1)`
confined to the **single y=1 row** (the y=3 row is never hit; only 2/10 candidates ever
fire). That data describes a degenerate instance, not the real game (see `../f5w3n/`
dynamics.txt vs the true `F5W3N.sexp`).

This dataset was regenerated by `prototypes/perc_invdyn/gen_f5w3n_seed1.py`: fresh
playthroughs through the real compiled interpreter under **non-zero per-episode seeds**
(train 101-108, test 301-302, test50 501-508), **20 steps each** (long enough to span
two enemy-fire events per episode, at observed steps 4 and 19), with a balanced
movement policy (`up` fire / `left` / `right` / `noop`). Observations are rendered by
the env's own `render_grid` (validated to reproduce the initial frame exactly:
enemies1 @ y=1 x∈{1,4,7,10,13}, enemies2 @ y=3 x∈{2,5,8,11,14}, hero gray @ (15,8)).

**Splits:** train (8 eps), test (2), test50 (8). Episodes are full trajectories, so
K-step temporal context is available inline (no separate train_regen/context-source dir
needed). Action whitelist: `left,right,up,noop` (movement game; **no `click`, no `down`**
— both are stated no-ops here).

**Enemy-fire randomness now exercised (verified in the generated data):**
spawn-row histogram `y=1: 16 fires, y=3: 10 fires` (BOTH rows), **14 distinct spawn
cells** — vs seed-0's 2 cells `{(1,1),(2,1)}` all in row y=1.

**Pipeline load** (`build_optim_viz.load_transitions`, whitelist `{left,right,up,noop}`,
context_k=3): train **152** transitions (noop 53 / up 38 / left 30 / right 31),
test **38**, test50 **152**; all four actions present in every split.

**Notes / surprises:** The hero fires `up` repeatedly, and on each fire step the red
bullet is drawn on the hero's cell, briefly occluding the gray hero for one frame (it
reappears next frame) — a documented render fact, not a death, and the action is still
correctly labeled `up`. Only **3/18** episodes end in a real (permanent) hero death, and
always on the **last** transition (obs 18→19) when fire#1's bullet reaches the bottom
row; the hero is alive and visible for the rest of every episode, so movement/fire
transitions stay identifiable.

Do NOT confuse with `../f5w3n` (the seed-0 original), which is left untouched.
