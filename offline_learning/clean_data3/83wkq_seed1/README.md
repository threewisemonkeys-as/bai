# 83wkq_seed1 — regenerated (non-degenerate) 83wkq data

`clean_data3/83wkq` was generated at **seed=0**, a pathological seed for this game. 83WKQ
is a `uniformChoice(adjPositions ...)` random walk: a click spawns a blue particle that then
picks a uniformly-random in-bounds orthogonal neighbor every non-click tick. Under **seed=0**
the RNG collapses and the walk degenerates into a **deterministic 1-D straight line + wall
bounce** — e.g. a particle spawned at row 8 slides col 8→0 then oscillates col 0↔1 forever,
with its **row never changing over 40 steps** (0 movement on one axis). That data describes a
degenerate instance, not the real game (see `../83wkq/dynamics.txt` vs the true `83WKQ.sexp`
and the sibling fix `../s2kt7_seed1/`).

This dataset was regenerated by `prototypes/perc_invdyn/gen_83wkq_seed1.py`: fresh playthroughs
through the real compiled interpreter under **non-zero per-episode seeds**, 14 steps each.
Observations are rendered by the env's own `render_grid` (validated to reproduce seed-0 data
byte-for-byte in `gen_s2kt7_seed1.py`). Under these seeds the particle wanders on **both axes**
(row deltas {-1,0,1} AND col deltas {-1,0,1}).

## Seeds (all non-zero, disjoint across splits)
- **train** (8 eps): seeds 101–108
- **test** (2 eps): seeds 301–302
- **test50** (8 eps): seeds 501–508

## Action policy (per episode)
Step 0 observes the empty grid; step 1 clicks to spawn a particle that then random-walks.
- **Even episodes** (0,2,4,…): a single particle walks ~12 uninterrupted noop steps — a long,
  clean, unconstrained 2-D walk (the primary non-degeneracy proof; interior spawns).
- **Odd episodes** (1,3,5,…): the spawn is on an edge/corner (boundary-adjacency, D4) and a
  second click is issued mid-episode (step 8–10) — the existing particle FREEZES on that click
  frame (D2 suppression) and a second walker is added.
Action whitelist: `noop,click`. Move verbs (left/right/up/down) are not emitted.

## Validation (see the run log)
- Pipeline load via `build_optim_viz.load_transitions(..., {noop,click}, context_k=3)`:
  train **104** transitions (92 noop / 12 click), test 26, test50 104 — both actions present.
- Non-degeneracy: **9/9** single-particle episodes move on BOTH axes (row-move 9/9, col-move 9/9).
- D2 click-frame suppression holds on 9/9 click frames; single-particle noop transitions
  moved 99/99 (particle never stays in place).

Episodes are full trajectories, so K-step temporal context is available inline (no separate
context-source dir needed). Do NOT edit `../83wkq/` — this is a separate `_seed1` corpus.
