# s2kt7_seed1 — regenerated (non-degenerate) s2kt7 data

`clean_data3/s2kt7` was generated at **seed=0**, a pathological seed where the game's
`(randomPositions GRID_SIZE 2)` on click always returns (0,0) — so clicks drop food at
(0,0) instead of scattering it. That data describes a degenerate instance, not the real
game (see `../s2kt7/` dynamics.txt vs the true `S2KT7.sexp`).

This dataset was regenerated by `prototypes/perc_invdyn/gen_s2kt7_seed1.py`: fresh
playthroughs through the real compiled interpreter under **non-zero per-episode seeds**
(train 101-108, test 301-302, test50 501-508), 14 steps each, with a noop/click policy
that exercises spawn(random)->ant-forage->eat. Observations are rendered by the env's own
`render_grid` (validated to reproduce seed-0 data byte-for-byte in `regen_s2kt7_seed.py`).

Splits: train (8 eps), test (2), test50 (8). Episodes are full trajectories, so K-step
temporal context is available inline (no separate train_regen/context-source dir needed).
Action whitelist: `noop,click`. In this data a click spawns 2 visible food at random cells
(23/24 train clicks are directly distinguishable from noop); click LOCATION stays
unidentifiable (irrelevant to dynamics).
