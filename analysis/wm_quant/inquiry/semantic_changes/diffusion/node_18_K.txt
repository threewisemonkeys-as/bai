world knowledge
- The grid is 9x9 (rows 0-8, cols 0-8). A vertical white column always exists at col=4; the set of rows with white cells changes only under the 'up' action and under clicks on white cells.
- 'up' action:
    - White rows cycle deterministically through four sets: 
        D = {0,1,2,3,4,5,6,7,8}
        A = {0,3,6}
        B = {0,1,3,4,6,7}
        C = {0,1,3,4,5,6,7,8}
      The mapping is: D → A, A → B, B → C, C → A.
    - All tokens (blue and red) move deterministically according to a rule that depends on the current white set; the exact mapping is consistent across instances and can be derived from the state.
- 'noop' action:
    - The set of white rows does not change.
    - All tokens move deterministically according to a rule that depends on the current state; the exact mapping is consistent and can be derived from the state.
- 'click ROW COL' action:
    - If the clicked cell is white (col=4): that white row is removed from the white set, and a red token appears at (ROW, COL). No other tokens move.
    - If the clicked cell is empty and col<4: a red token appears at (ROW, COL). Additionally, all blue tokens move deterministically according to a rule that depends on the click coordinates and the current state; the exact movement is consistent across instances.
    - If the clicked cell is empty and col>4: a blue token appears at (ROW, COL). Additionally, all red tokens move deterministically according to a rule that depends on the click coordinates and the current state.
    - If the clicked cell contains a blue token: no new token appears, but all red tokens move deterministically according to a rule that depends on the click coordinates and the current state.
    - If the clicked cell contains a red token: no new token appears, but all blue tokens move deterministically according to a rule that depends on the click coordinates and the current state.
- All dynamics are deterministic: given the current state and action, the next state is uniquely determined.
